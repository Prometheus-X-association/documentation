# Contribute to these docs

This documentation is shared by everyone who builds on Prometheus-X. Corrections and improvements are welcome.

## Fixing or improving a page

1. Use the edit button at the top of the page, or fork the documentation repository.
2. Make your change in Markdown under `docs/`.
3. Preview it with `mkdocs serve` (see the repository README).
4. Open a pull request describing what you changed and why.

## Writing style in short

- Write for someone who has never heard of the component you describe.
- Start each page with what the reader gets out of it.
- Prefer short sentences, concrete examples and diagrams over long explanations.
- Use the terms of the [glossary](learn/glossary.md).
- Link to existing pages instead of re-explaining them.
- Keep internal details out: no credentials, no internal hostnames, no unreleased security information.
